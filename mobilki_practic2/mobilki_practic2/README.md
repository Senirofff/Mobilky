# Заметки (mobilki_practic2)

Приложение «Заметки» на Flutter — учебная работа по теме
«Работа с текстом в Flutter: `TextEditingController` и `ListView»».

## Что умеет

- ввод текста в поле и сохранение заметки по кнопке **«Сохранить»**;
- список заметок: новые добавляются в начало, у каждой — время создания
  («5 минут назад») и кнопки правки и удаления;
- **редактирование** заметки: текст переносится в то же поле ввода,
  повторное «Сохранить» применяет правку, «Отмена» возвращает поле в исходное
  состояние;
- **удаление** заметки;
- счётчик заметок в шапке и подсказка, пока заметок нет.

Всё, что нужно по заданию, работает на чистом Flutter без внешних пакетов.
Заметки живут в памяти и очищаются при перезапуске приложения.

## Структура

```
lib/
  main.dart                    запуск приложения
  theme/app_theme.dart         цвета и общая тема
  models/note.dart             заметка (текст и дата создания)
  utils/format.dart            «5 минут назад», склонения числительных
  screens/notes_screen.dart    экран со списком и логикой заметок
  widgets/
    note_composer.dart         поле ввода + кнопка «Сохранить»
    note_card.dart             карточка заметки
    empty_notes.dart           заглушка, когда заметок нет
```

## Запуск

```bash
flutter pub get
flutter run
```

## Тесты

```bash
flutter test
```

`test/widget_test.dart` проверяет сценарии из задания (сохранение, правка,
отмена правки, удаление), `test/layout_test.dart` — что вёрстка не ломается
на узких экранах и при крупном системном шрифте.
